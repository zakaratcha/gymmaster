# Экраны кабинета тренера

Нумерация условная; порядок — от часто используемых к реже.

**Активная тренировка** в зале ведётся во **втором и последующих табах** верхней полосы (см. `01-shell-and-navigation.md`). Поведение экрана тренировки — в **`04-active-workout-tab.md`**.

---

## 1. Список клиентов (вкладка «Клиенты»)

**Цель:** быстрый выбор клиента, переход к его данным (**UX-001**).

```
┌─────────────────────────────────────┐
│ Клиенты                    [+ Добавить]
├─────────────────────────────────────┤
│ 🔍 Поиск по имени…                  │
├─────────────────────────────────────┤
│ Недавние                            │
│  ┌─────────────┐ ┌─────────────┐    │
│  │ Анна        │ │ Иван        │    │  ← горизонтальные чипы/карточки
│  └─────────────┘ └─────────────┘    │
├─────────────────────────────────────┤
│ Все клиенты                         │
│  Анна Иванова          >            │
│  Иван Петров           >            │
│  …                                  │
└─────────────────────────────────────┘
                                [+] FAB опционально дублирует «Добавить»
```

- **[+ Добавить]** — создание клиента (**CLIENT-001**): минимум имя, опционально заметки/контакты, **вес тела (кг)** для объёма и упражнений от собственного веса (`04-active-workout-tab.md`).
- Строка клиента → **карточка клиента** (экран 2).

---

## 2. Карточка клиента (хаб)

**Цель:** одна точка входа в планы, тренировку, историю; видно «что сейчас важно».

```
┌─────────────────────────────────────┐
│ ←  Анна Иванова            [Править]│
├─────────────────────────────────────┤
│ Заметки (свёрнутая строка, раскрыть)│
├─────────────────────────────────────┤
│ Вес тела (опц.)  [ 72 кг ]          │  ← для объёма «свой вес» и статистики завершения
├─────────────────────────────────────┤
│ ▶ Тренировка в процессе             │  ← только если у этого клиента in_progress
│   ноги · с 18:02          [Открыть] │  ← открывает соответствующий верхний таб
├─────────────────────────────────────┤
│ Ближайший план                      │
│   ср 07.05 · ноги         [Открыть] │
│   + ещё N запланировано   [Все планы]│
├─────────────────────────────────────┤
│ Действия                            │
│  [ Старт с плана ▼ ]  [ Пустая сессия ]│
├─────────────────────────────────────┤
│ История                             │
│  [ Последние тренировки ]             │  → список/фильтр по тегу (DASH-001)
│  [ История упражнения… ]            │  → выбор упражнения → экран 6
├─────────────────────────────────────┤
│ Сплит (теги типа дня)               │
│  ноги · верх · день А  [+ тег] [⚙]  │  пул для автодополнения (**SPLIT-001**)
└─────────────────────────────────────┘
```

- **Старт с плана ▼** — выбор одного из предстоящих планов → открывается **вкладка тренировки** с префиллом из плана (`04-active-workout-tab.md`).
- **Пустая сессия** — новая `in_progress` без `plannedWorkoutId`; если уже есть in_progress у клиента — модальное **FACT-004**: завершить / отменить / открыть текущую.
- **Все планы** — экран 3.
- **Править** — форма клиента: в т.ч. **вес тела** (**кг**, опционально) — для расчёта нагрузки в упражнениях **от массы тела** и для строки **«общий поднятый вес»** в окне завершения тренировки (`04-active-workout-tab.md`). Без веса такие подходы в объёме могут не войти или расчёт будет неполным.
- **Ошибочно завершили** — в **основном интерфейсе** (на карточке клиента и/или в деталях последней **завершённой** сессии) действие **«Вернуть в зал»** / **«Продолжить тренировку»**: сессия снова становится `in_progress`, снова появляется **верхний таб**, содержимое — как в `04-active-workout-tab.md`. Требует **поддержки доменной модели и API** (повторный переход из `completed` в `in_progress` или эквивалент); до согласования с `03-functional-requirements.md` трактовать как целевой UX.

## 3. Предстоящие планы клиента

**Цель:** список всех будущих планов, сортировка от ближайшей даты (**PLAN-003**).

```
┌─────────────────────────────────────┐
│ ←  Планы · Анна            [+ План] │
├─────────────────────────────────────┤
│ 07.05 · ноги              [···]    │
│ 09.05 · верх              [···]    │
│ …                                   │
└─────────────────────────────────────┘
```

- Строка → **редактор плана** (экран 3b).
- **[+ План]** — новый план: дата, **тег типа дня** (существующий или новый), затем список упражнений (**PLAN-001**, **PLAN-002**).

---

## 3b. Редактор плана (создание / правка)

```
┌─────────────────────────────────────┐
│ ←  План тренировки         [Сохранить]│
├─────────────────────────────────────┤
│ Дата          [ 07.05.2026      ]   │
│ Тег дня       [ ноги ▼ или ввод ]   │
├─────────────────────────────────────┤
│ Упражнения (перетаскивание порядка) │
│  1. Присед …  4×8 · 80 кг  отдых 90 с  [≡][✎][🗑]│
│  2. …                               │
├─────────────────────────────────────┤
│ [ + Упражнение ]                    │  → выбор из справочника (не архивные)
└─────────────────────────────────────┘
```

- Поля подходов: число подходов, повторы, вес **кг**; **отдых между подходами** (секунды или мм:ss) — для таймера на экране активной тренировки (`04-active-workout-tab.md`); RPE и прочее — по мере необходимости.

## 4. Завершённая тренировка: план ↔ факт

**Цель:** наглядное сравнение (**UC-04**, **CMP-001**). Если сессия **без плана** — блок «план» скрыт или показывается пояснение.

```
┌─────────────────────────────────────┐
│ ←  07.05 · Анна · ноги              │
├─────────────────────────────────────┤
│ [ Сводка ] [ По упражнениям ]       │
├─────────────────────────────────────┤
│ Упражнение        план    факт      │
│ Присед            4×8@80  4×8@82.5  │  ← отклонения визуально (цвет/иконка)
│ …                                   │
├─────────────────────────────────────┤
│ С прошлой «ноги» (05.04)   [Подробнее]│  → экран 5 (**CMP-002**)
│  [ Вернуть в зал ]                  │  если ошибочно завершили; см. карточку клиента
└─────────────────────────────────────┘
```

- Кнопка **«Вернуть в зал»** дублирует действие с карточки клиента (см. раздел 2).

## 5. Сравнение с прошлой аналогичной (**UC-05**)

```
┌─────────────────────────────────────┐
│ ←  Сравнение: ноги                  │
│     Текущая: 07.05 · Прошлая: 05.04 │
├─────────────────────────────────────┤
│ Свёлка (объём / ключевые упражнения)│
├─────────────────────────────────────┤
│ По упражнениям (общие позиции)      │
│  Присед: 82.5 кг → 80 кг  (Δ …)    │
└─────────────────────────────────────┘
```

Детализация **Should**-уровня; для MVP достаточно таблицы по совпадающим упражнениям.

**Вход:** с карточки клиента или со строки упражнения в завершённой сессии.

```
┌─────────────────────────────────────┐
│ ←  История: Присед · Анна           │
├─────────────────────────────────────┤
│ [ Таблица ] [ График ]              │  график — когда будет готова библиотека
├─────────────────────────────────────┤
│ дата       подходы     комментарий  │
│ 07.05      4×8@82.5                 │
│ 05.04      4×8@80                   │
│ …                                   │
└─────────────────────────────────────┘
```

## 7. Справочник упражнений (вкладка «Упражнения»)

```
┌─────────────────────────────────────┐
│ Упражнения                 [+ Создать]
├─────────────────────────────────────┤
│ 🔍 Поиск…                           │
├─────────────────────────────────────┤
│  Присед со штангой         [Архив]  │
│  …                                  │
├─────────────────────────────────────┤
│ [ Архив (Could) ]                   │  EX-ARCH-UI-001
└─────────────────────────────────────┘
```

- Строка → карточка/форма редактирования (название, заметки по желанию).
- **Архив** — мягкое скрытие из выборщика для новых планов/фактов (**EX-000**).

---

## Состояния общие

| Состояние | Поведение |
|-----------|-----------|
| Загрузка | Скелетон или спиннер в области контента |
| Пустой список клиентов | CTA «Добавить клиента» |
| Нет предстоящих планов | Подсказка + кнопка «Создать план» |
| Ошибка сети | Сообщение + «Повторить» |
