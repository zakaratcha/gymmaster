# Вкладка активной тренировки (в зале)

Отдельный **таб верхней полосы** (см. `01-shell-and-navigation.md`): у каждой сессии `in_progress` своя вкладка. Содержимое вкладки — полноэкранный **режим ведения тренировки** под этот клиент/сессию.

**Цель:** мгновенный ввод факта (**FACT-002**), фокус на **текущем упражнении**, понятный **отдых**, быстрый выход в основной интерфейс через первый таб той же верхней полосы (**UX-002**).

---

## Скелет экрана (одна вкладка)

Полоса **«Главная | … активные тренировки …»** — общая для кабинета; здесь не дублируется (см. `01-shell-and-navigation.md`). Ниже — только содержимое **выбранного** таба сессии.

```
┌─────────────────────────────────────┐
│ ← (к основному сценарию)   [···]    │  ← локальный bar: назад = первый таб; ··· — меню тренировки
│     Анна · ноги · с 18:02            │
├─────────────────────────────────────┤
│  ТЕКУЩЕЕ УПРАЖНЕНИЕ            [📜] │  ← справа иконка: история этого упражнения у клиента
│         Присед со штангой           │     (крупно название; порядок в тренировке — при необходимости)
├─────────────────────────────────────┤
│  План на это упражнение (кратко)    │  если есть из плана: N×цель, отдых …
│  или «вне плана»                    │
├─────────────────────────────────────┤
│  Счётчик отдыха                     │  см. раздел «Отдых»
│  [ Старт / сброс ]   метка фазы отдыха │
├─────────────────────────────────────┤
│  Подходы (текущее упражнение)       │  см. раздел «Подходы»
│  …                                  │
├─────────────────────────────────────┤
│  [ Следующее упражнение ]           │  или авто-переход по правилам ниже
│  [ Другое упражнение ▼ ]            │  вне очереди: из тренировки / каталог / новое
├─────────────────────────────────────┤
│  [ Завершить тренировку ]           │  после подтверждения вкладка исчезает
└─────────────────────────────────────┘
```

- **● / ○** в `01-shell-and-navigation.md` — пример **иконки статуса рядом с именем на табе** (не отдельная длинная подпись); конкретная графика — в дизайне.

---

## Текущее упражнение

- Справа в **той же строке**, что и заголовок **«Текущее упражнение»**, — **иконочная кнопка**: открыть **историю этого упражнения у этого клиента** (`02-trainer-screens.md`, раздел 6, **HIST-001**). Реализация: модалка, полноэкранный экран или нижний шит; по закрытию — снова вкладка тренировки, состояние сессии **не сбрасывать**.
- Показываются **название**, при необходимости **порядковый номер** в списке дня.
- Краткая строка контекста: **старт с плана** / **без плана** / смесь (если упражнение добавлено вне плана).

Доступ к **полному списку упражнений** этой сессии (для сверки порядка, свайпа к другому) — через **«⋯»** или вторичную зону «все упражнения дня» (сворачиваемый блок), без конкурирования с главным фокусом — по вкусу вёрстки.

---

## Подходы: зафиксировать факт

Для **запланированных** подходов (из плана, перенесённых в сессию):

- Строка подхода: цель плана (повторы × вес **кг**), действия:
  - **отметить выполненным** с целями как есть;
  - **изменить** повторы и/или вес, затем **отметить выполненным**.

Для **сверхплана** / дополнительных:

- **[+ Подход]** добавляет фактический подход (ввод повторов, веса), без привязки к «слоту» плана.

Редактирование уже отмеченного подхода — по правилам автосохранения (**FACT-002**).

**Пропуск** запланированного подхода или **пропуск упражнения** целиком — через явные действия (кнопка/меню), чтобы план↔факт после завершения оставался честным (**CMP-001**).

---

## Отдых между подходами

- У **каждого упражнения в плане** задаётся **длительность отдыха** (секунды или мм:ss) между подходами (**в редакторе плана**, см. `02-trainer-screens.md` → 3b). Для упражнений **без плана** или без заданного отдыха — значение по умолчанию (фиксированное в настройках позже) или поле «отдых» вручную на экране тренировки — **уточнить при реализации**; в документе закладываем: таймер опирается на число из плана, иначе дефолт.
- **Никаких** пушей, системных уведомлений и звуков **в MVP**: только счётчик на экране и **метка состояния на вкладке** верхней полосы:
  - **«Отдых»** — пока идёт обратный отсчёт (или пауза, если решим);
  - **«Пора» / нейтрально** — отдых не идёт или истёк; можно интерпретировать как «пора пахать» без пафоса в копирайте.
- Кнопки: **старт отдыха** (часто автоматически после отметки подхода — по желанию), **сброс**, **пропустить отдых**.

---

## Следующее упражнение и автопереход

- **[Следующее упражнение]** переводит фокус на следующее в **текущем порядке** списка сессии.
- **Автоматический** переход к следующему упражнению, если **план по текущему** считается выполненным (все запланированные подходы отмечены или явно пропущены по правилам продукта): мягкая анимация или короткое подтверждение «Упражнение закрыто → дальше» — без блокирующего модала, если не нужен.
- Если **текущее упражнение вне плана** или без чёткой «цели по числу подходов» — автопереход **не срабатывает**; только ручной **«Следующее»** или выбор **«Другое упражнение»**.

---

## Другое упражнение (не по порядку)

**[Другое упражнение ▼]** открывает выбор:

1. **Уже в этой тренировке** — быстрый список упражнений сессии (переключить фокус).
2. **Из справочника** — поиск по каталогу (**только не архивные** для новых добавлений, **EX-000**).
3. **Создать новое** — короткая форма; новое упражнение попадает в справочник и в текущую сессию.

После выбора фокус переключается на это упражнение; порядок в сессии обновляется по правилу (в конец / после текущего) — **зафиксировать в доменной логике**.

## Завершить тренировку

- Кнопка **внизу** зоны безопасного нажатия (чтобы не промахнуться).
- **Окно подтверждения** — не только «Завершить?», а краткая **сводка** (одним взглядом перед сохранением):
  - **Длительность** — время от старта сессии до «Завершить» (мм:ss или ч+мм при длинных).
  - **Выполнение плана** — **процент** по согласованной формуле (например: доля **отмеченных запланированных подходов** от всех запланированных в связанном плане; при старте без плана — прочерк или «нет плана»).
  - **Общий поднятый объём** — сумма **кг×повторы** по подходам **кг** (см. ниже); одна строка **кг** + одна строка **шуточная пересчитанная величина** (см. ниже).
- Кнопки: **Отмена** / **Завершить и сохранить**.
- После успеха: сессия → **завершена** (**FACT-001**), **вкладка** закрывается, фокус на **первый таб** или соседнюю активную.
- Переход к экрану **план ↔ факт** — опционально сразу после завершения, либо из истории.

### Объём (кг) и вес клиента

- В **подсчёт входят** подходы, где задан **дополнительный вес** (штанга, гантели и т.д.) — классически «повторы × вес снаряда».
- Для упражнений **с нагрузкой от массы тела** (подтягивания, отжимания, часть тренажёров и т.п.) в формулу должен входить **вес тела клиента** — он хранится **на странице/карточке клиента** (см. `02-trainer-screens.md` → раздел 2, форма **Править**). Если вес не задан — такие подходы в объёме **не учитывать** или показывать с **предупреждением** «заполни вес клиента для точного объёма» — **выбрать при реализации**; в UI спеки заложено: поле **опционально**, **кг**.
- Детализация по типам упражнений (флажок «с собственным весом» в справочнике и т.д.) — **этап доменной модели**; до появления — достаточно правила + вес клиента.

### Шуточное измерение («поднял N слонов»)

- После расчёта **суммарных кг** показать **одну** фразу вида: «Это как **2,34 слона**» / «**4,1 лошади**» / «**0,07 синего кита**» — **не** научная точность, а **настроение**.
- Алгоритм: заранее завести **большой пул** записей **{ референсная масса в кг, три формы названия для русского числа }** — как аргументы [`pluralize`](https://www.npmjs.com/package/numeralize-ru) из **`numeralize-ru`** (так же, как в **gisportal**, `portal-ui`: `import { pluralize } from 'numeralize-ru'` — например `pluralize(n, 'файл', 'файла', 'файлов')`). Для слона: `pluralize(n, 'слон', 'слона', 'слонов')`. Животные, крупные объекты, мемы — **50+ позиций**, пул допускается пополнять. При **каждом** открытии окна завершения **случайно выбрать** одну запись, **разделить** суммарный объём (кг) на референс, вывести **1 знак** после запятой; целое **n** для `pluralize` взять от отображаемого значения по согласованному правилу (например **целая часть** или **округление**, чтобы не ломать согласование «число ↔ форма»).
- Цель пула — чтобы **реже повторялось** подряд; **псевдослучай** без запоминания «что показывали вчера» допустим; при желании позже — «не повторять последние K завершений».
- **Примеры** единиц в пуле (не исчерпывающий список; у каждой в коде — **референс кг** + **три формы** под `numeralize-ru`): слон, лошадь, бегемот, медведь, рояль, легковой автомобиль, кит, синий кит, жираф, фортепиано… — полный набор **в коде/локали**, не в спеке.

```
┌ Завершить тренировку? ─────────────┐
│  54 мин · План ~82% · Объём 4 860 кг │
│  Где-то 0,81 слона.                 │  ← случайная единица из пула
│  [ Отмена ]  [ Завершить и сохранить ]│
└─────────────────────────────────────┘
```

## Связь с основным интерфейсом

- Первый таб верхней полосы — **как раньше**: клиенты, планы, вкладка «Упражнения», «Ещё», нижняя навигация. При переключении с таба тренировки на **Главный** контекст тренировки **не теряется** (сессия остаётся `in_progress`).
- Кнопка **«←»** в локальном app bar вкладки тренировки дублирует смысл «выйти в основной интерфейс» = выбрать первый таб (не завершая сессию).

## Открытые моменты (на потом)

- Точные правила **автостарта** таймера отдыха после отметки подхода.
- **Пауза** тренировки (глобальная) — вне MVP, если не потребуется.
- Индикатор на табе при **нескольких** одновременных отдыхах (по одному клиенту таб один) — не применимо.
