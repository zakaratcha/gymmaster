# Вход, профиль и администрирование

## 1. Вход (**AUTH-001**)

Экран входа **не привязан к отдельному маршруту**: при отсутствии сессии форма показывается **как состояние** текущего URL (см. `01-shell-and-navigation.md`). После успешного входа по запросу **`/admin/...`** учётка **без** `platform_admin` уходит **редиректом** на начальную страницу кабинета тренера.

Нет публичной регистрации; только поля учётных данных.

```
┌─────────────────────────────────────┐
│           GymMaster                 │
├─────────────────────────────────────┤
│  Email или логин                    │
│  [________________________]         │
│  Пароль                             │
│  [________________________]         │
│                                     │
│  [        Войти        ]            │
│                                     │
│  (Восстановление пароля — позже;    │
│   сброс через админа по FR)         │
└─────────────────────────────────────┘
```

- Успех → целевой экран по текущему маршруту; в обычном сценарии — **вкладка «Клиенты»** / home; если открывали админку без прав — уже **редирект** в кабинет (см. выше).
- Ошибка — текст под формой без утечки «существует ли пользователь».

## 3. Раздел администрирования (**ADMIN-001** … **ADMIN-003**)

**Доступ:** только роль `platform_admin`. Нельзя назначать/снимать эту роль из UI (**ADMIN-004**).

### 3a. Список учёток тренеров

```
┌─────────────────────────────────────┐
│ ←  Администрирование       [+ Создать]
├─────────────────────────────────────┤
│  email           статус             │
│  trainer@…       активен      [···] │
│  other@…         заблокирован [···] │
└─────────────────────────────────────┘
```

- **[+ Создать]** → форма **3b**.
- Меню **···** по строке: **Заблокировать** / **Разблокировать**, **Сброс пароля** (новый временный / инструкция — по реализации **ADMIN-003**).
- Список **не** показывает клиентов или тренировки (нет кросс-тенантного доступа к данным).

### 3b. Создание учётки тренера (**ADMIN-002**)

```
┌─────────────────────────────────────┐
│ ←  Новый тренер                     │
├─────────────────────────────────────┤
│  Email (логин)                      │
│  [________________________]         │
│  Пароль / отметка «задать при       │
│  первом входе» (как решим в API)    │
│  [________________________]         │
│                                     │
│  ℹ️ При создании: новый trainerId, │
│  сид упражнений копируется в спр-ник│
│                                     │
│  [ Создать ]                        │
└─────────────────────────────────────┘
```

После создания — возврат к списку или экран успеха с кратким резюме (email, статус).

---

## Заметки по безопасности UI

- Раздел `/admin` при отсутствии роли — **редирект** на кабинет или **403** страница без деталей.
- Действия «сброс пароля», «заблокировать» — **подтверждение** модальным окном.
