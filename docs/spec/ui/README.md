## Принципы UX для зала

1. **Активные тренировки** (`in_progress`) всегда доступны **не глубже 1–2 касаний** (**UX-002**).
2. **Несколько клиентов в зале** — через **верхние табы** тренировок. **Переключение контекста в кабинете** (чьи планы/карточка) — **1–2 действия** от типичных экранов: **недавние**, **поиск** (**UX-001**); отдельной полосы «один текущий клиент» на всю «Главную» нет.
3. **План ↔ факт** и **сравнение с прошлой аналогичной** — наглядно, без «прятать» в подменю (**UC-04**, **UC-05**).
4. На одного клиента **не более одной** сессии `in_progress`; при попытке второй — явный выбор: завершить/отменить текущую (**FACT-004**).
