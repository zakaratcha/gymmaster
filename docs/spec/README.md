# Спецификация GymMaster

Веб-инструмент для тренера: планы и факт тренировок по клиентам, статистика, работа со сплитом.

## Оглавление

| Документ | Описание |
|----------|----------|
| [00-vision.md](./00-vision.md) | Видение, границы, глоссарий |
| [01-open-questions.md](./01-open-questions.md) | Исходные вопросы и зафиксированные ответы |
| [02-personas-and-use-cases.md](./02-personas-and-use-cases.md) | Персона и сценарии MVP |
| [03-functional-requirements.md](./03-functional-requirements.md) | Функциональные требования (MoSCoW) |
| [04-non-functional-requirements.md](./04-non-functional-requirements.md) | Нефункциональные требования |
| [05-tech-and-data.md](./05-tech-and-data.md) | Веб-стек, данные, сущности |

## Как пользоваться

1. Ядро продукта описано в `00-vision.md` и `03-functional-requirements.md`.
2. Зафиксировано: **один сервер + SQLite**; **веса только в кг**; сплит — **свободные теги**; планы — **цепочка** будущих тренировок; **в системе только учётки тренеров** (у части дополнительно **`platform_admin`**, выдаётся **только вне** UI приложения); раздел **администрирования** — отдельный UI; саморегистрации нет; сид упражнений при **создании** новой учётки из админ-раздела; изоляция данных по `trainerId` (`00-vision.md`, `03-functional-requirements.md`, `05-tech-and-data.md`).

**Версия:** **0.6** (все пользователи — тренеры; `platform_admin` только вне UI; без саморегистрации).
