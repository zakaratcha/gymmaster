# GymMaster

Веб-кабинет тренера: планы тренировок, фиксация факта в зале, сравнение с выполнением.

> Проект в стадии разработки: pet-проект, работающий MVP-каркас. Функциональность и API ещё меняются.

## Что уже работает

- вход/выход, сессия, профиль тренера;
- изоляция данных по `trainerId`: у каждого тренера свои клиенты, планы и тренировки;
- CRUD клиентов: заметки, вес тела;
- личный справочник упражнений с архивацией;
- планы тренировок на будущее: дата, тег типа дня, упражнения с целевыми подходами и весом;
- тренировка в процессе: старт с плана или с нуля, фиксация подходов, внеплановые упражнения, завершение;
- несколько текущих тренировок у разных клиентов с переключением во вкладках.

## Стек

- Frontend: React 19, TypeScript, MobX, Vite, Storybook, SCSS/БЭМ;
- Backend: Node.js, Express, SQLite (Drizzle ORM), bcrypt;
- Тесты: Cucumber + Playwright (e2e и API).

## Запуск

```bash
npm install
npm run dev   # http://127.0.0.1:5173
```

Локальные dev-аккаунты: `first-admin@local` и `second-trainer@local`, пароль `changeme`.

Тесты: `npm run test:e2e`, `npm run test:api`. Линт и типы: `npm run lint`.
