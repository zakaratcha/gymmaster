# GymMaster

Веб-кабинет тренера: планы тренировок, фиксация факта в зале, сравнение с выполнением.

> **Проект в стадии разработки.** Pet-проект, работающий MVP-каркас: основной сценарий «клиент → план → тренировка → факт» закрыт, функциональность и API ещё меняются.

## Зачем

Тренер ведёт нескольких клиентов и в зале быстро переключается между ними. GymMaster решает три рутинные задачи:

- быстро составить индивидуальный план тренировки на будущее;
- зафиксировать факт: упражнения, подходы, веса, повторы — без лишних шагов;
- увидеть расхождения между планом и фактом и сравнить тренировку с прошлой «такой же» по тегу дня (сплиту).

## Что уже работает

- **Аутентификация** — вход/выход, сессия в cookie, профиль тренера.
- **Изоляция данных** — у каждого тренера свой `trainerId`; все запросы фильтруются по текущему тренеру, чужие данные недоступны.
- **Клиенты** — CRUD карточек клиентов, заметки, вес тела.
- **Справочник упражнений** — личный список тренера с мягким удалением (архивация): архивные упражнения не попадают в новые планы, но остаются валидными в старых записях.
- **Планы тренировок** — сколько угодно будущих планов на клиента, у каждого дата и тег типа дня, упражнения с целевыми подходами/весом/повторами.
- **Жизненный цикл тренировки** — старт с плана (или с нуля), фиксация подходов по ходу, добавление внеплановых упражнений, завершение сессии как «факта».
- **Параллельные тренировки** — несколько текущих тренировок у разных клиентов одновременно, переключение между ними во вкладках.

## Стек

- Frontend: React 19, TypeScript, MobX, Vite, Storybook, SCSS/БЭМ;
- Backend: Node.js, Express, SQLite (Drizzle ORM), bcrypt;
- Тесты: Cucumber + Playwright (e2e и API).

## Структура

```
src/
  blocks/      UI-компоненты по БЭМ
  services/    клиентские сервисы по доменам: auth, clients, exercises, plans, workoutSessions
  stores/      MobX-сторы
  server/      Express API, миграции и сид справочника упражнений
tests/
  e2e/, api/   Gherkin-сценарии
  _harness/    Page Object и step definitions
docs/
  spec/        продуктовая спецификация
  code/        описание архитектуры
```

## Запуск

```bash
npm install
npm run dev   # http://127.0.0.1:5173
```

Локальные dev-аккаунты: `first-admin@local` и `second-trainer@local`, пароль `changeme`.

Тесты: `npm run test:e2e`, `npm run test:api`. Линт и типы: `npm run lint`.
