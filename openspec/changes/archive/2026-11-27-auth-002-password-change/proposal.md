# Предложение

## Зачем

Тренер уже входит в приложение, выходит из него и видит свою учётку в Профиле, но поменять собственный пароль не может (**AUTH-002**). Единственный путь сейчас — попросить администратора сбросить пароль на временный, и даже после этого тренер остаётся с паролем, который знает кто-то ещё. Раздел администрирования со сбросом пароля уже готов, поэтому самостоятельная смена пароля закрывает оставшийся пробел в управлении доступом.

## Границы изменения

### Входит

- пункт «Сменить пароль» в Профиле у любой вошедшей учётки, независимо от роли `platform_admin`;
- экран «Смена пароля» внутри кабинета тренера по спецификации UI: «←» возвращает в Профиль, поля «Текущий пароль», «Новый пароль», «Повтор нового» и действие «Сохранить»;
- проверка совпадения нового пароля с повтором на клиенте до обращения к серверу: при несовпадении показывается «Пароли не совпадают», и пароль не меняется;
- смена пароля только своей учётки — той, чья сессия выполняет запрос; указать другую учётку нельзя;
- подтверждение текущим паролем: при неверном текущем пароле показывается «Неверный текущий пароль», пароль и сессия остаются прежними;
- проверка нового пароля по тем же правилам длины, что при создании учётки администратором, с тем же текстом ошибки; пустые поля отклоняются с ошибкой «Проверьте введённые данные»;
- после успешной смены прежние сессии этой учётки перестают действовать, а тренер остаётся в приложении с новой сессией и возвращается в Профиль;
- смена пароля атомарна: если новая сессия не выпущена, пароль остаётся прежним;
- без сессии операция отклоняется, а в интерфейсе показывается форма входа;
- запрос смены пароля в коллекции ручных запросов API рядом с входом.

### Не входит

- восстановление пароля по email без участия администратора (**AUTH-EMAIL-001**);
- сброс пароля другой учётки администратором — он уже есть в разделе администрирования;
- принудительная смена временного пароля при следующем входе;
- требования к сложности пароля сверх минимальной длины;
- пустая сессия и экран активной тренировки из спецификации вкладки тренировки.

## Функциональности

### Новые функциональности

- `auth/password`: смена собственного пароля вошедшим тренером — доступ к экрану из Профиля, подтверждение текущим паролем, проверка нового пароля и повтора, замена прежних сессий учётки новой без выхода из приложения.

## Внешнее влияние

- в HTTP API рядом со входом, выходом и текущим пользователем появляется операция смены собственного пароля; изменение аддитивное, существующие ответы не меняются;
- успешная смена пароля прекращает действие всех прежних сессий учётки, в том числе на других устройствах;
- в SPA появляются экран `/account/password` и пункт «Сменить пароль» в Профиле.
