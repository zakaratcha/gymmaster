# Предложение

## Зачем

- Блок «Сплит» на карточке клиента — заглушка: теги вписаны в код, `+ тег` и `⚙` не работают, висит метка «Скоро».
- В редакторе плана тег вводится свободным текстом без подсказок. Поэтому «ноги» и «Ноги» получаются разными тегами, и сравнение с прошлой аналогичной тренировкой (CMP-002) их не связывает.
- SPLIT-001 — последнее требование из Must, которое закрыто только заглушкой.

## Границы изменения

### Входит

- Пул тегов сплита у клиента: тренер видит теги в блоке «Сплит» и пополняет пул через `+ тег`. Метка «Скоро» и кнопка `⚙` из блока убираются.
- API тренера для чтения и пополнения пула. Доступ только к своим клиентам, чужой или несуществующий клиент — «не найдено».
- Регистр не различается: теги, которые отличаются только регистром, — один тег. В пуле остаётся написание, которое попало туда первым. План и тренировка сохраняются с тегом в этом написании.
- Новый тег, введённый в плане или при старте тренировки без плана, после сохранения попадает в пул.
- Редактор плана: подсказки тега из пула клиента, новый тег можно ввести вручную.
- Старт тренировки без плана с карточки клиента («Пустая сессия»): тренер выбирает тег из подсказок пула или вводит новый. В интерфейсе сейчас нет такого действия, хотя сервер умеет начинать тренировку без плана.
- Прошлая аналогичная тренировка ищется по тегу без учёта регистра.

### Не входит

- Фильтр «Последние тренировки» по тегу (DASH-001).
- Удаление и переименование тегов пула, настройки сплита (`⚙`).
- Глобальные теги тренера, общие для всех клиентов.
- Перенос в пул тегов из уже сохранённых планов и тренировок и приведение их регистра к написанию из пула. Реальных данных пока нет, это решение пользователя.

## Функциональности

### Новые функциональности

- `workout/split`: пул тегов сплита клиента — просмотр и пополнение, правила совпадения тегов (без учёта регистра, после обрезки пробелов), подсказки при выборе тега в плане и при старте тренировки без плана, пополнение пула новым тегом.

### Изменяемые функциональности

- `workout/previous-workout-comparison`: «тот же тег» при выборе прошлой аналогичной тренировки теперь совпадает без учёта регистра.

## Внешнее влияние

- Новый тренерский API пула тегов клиента и коллекция Bruno для него.
- Создание и изменение плана и старт тренировки сохраняют тег в написании из пула, поэтому сохранённый тег может отличаться от введённого регистром. Формат запросов и ответов не меняется.
