# Предложение

## Зачем

Тренер видит завершённую тренировку и её сравнение с планом, но не может сопоставить её с прошлой тренировкой того же типа дня у того же клиента (**CMP-002**, **UC-05**). Без этого прогресс по весам и объёму приходится восстанавливать вручную, а тренировки без плана вообще не с чем сравнить. Сравнение план ↔ факт (**CMP-001**) уже готово, и экран завершённой тренировки — естественная точка входа для следующего сравнения.

## Границы изменения

### Входит

- определение прошлой аналогичной тренировки для завершённой: последняя завершённая тренировка того же тренера, того же клиента и с тем же тегом дня, завершённая строго раньше текущей; тренировки в процессе, с другим тегом, другого клиента и сама текущая не подходят;
- сравнение работает одинаково для тренировок, начатых с плана и без плана;
- на экране завершённой тренировки — переход «С прошлой „<тег>“ (<дата>)» и «Подробнее», если прошлая аналогичная есть; если её нет — перехода нет;
- отдельный экран сравнения с прошлой тренировкой: тег, даты текущей и прошлой тренировок, сводка по объёму и строки по упражнениям с фактом прошлой, фактом текущей и разницей;
- сопоставление упражнений: общие — парами, упражнение только из одной тренировки — отдельной строкой, повтор одного упражнения сопоставляется сначала по точно совпадающим подходам, затем остаток;
- чтение данных прошлой аналогичной тренировки через тренерский API с изоляцией по тренеру.

### Не входит

- история по упражнению (**HIST-001**) и графики;
- таймер отдыха;
- отмена тренировки;
- изменения сравнения план ↔ факт (**CMP-001**);
- выбор произвольной тренировки для сравнения вместо последней аналогичной.

## Функциональности

### Новые функциональности

- `workout/previous-workout-comparison`: поиск прошлой аналогичной завершённой тренировки, переход к сравнению с экрана завершённой тренировки и экран сравнения текущей и прошлой тренировок по объёму и упражнениям.

## Внешнее влияние

- тренерский HTTP API расширяется чтением прошлой аналогичной тренировки для завершённой сессии клиента; изменение аддитивное, существующие ответы не меняются;
- в SPA появляется новый маршрут экрана сравнения с прошлой тренировкой.
