# workout/previous-workout-comparison Specification

## Purpose

Функциональность позволяет тренеру сравнить завершённую тренировку клиента с прошлой аналогичной: последней завершённой тренировкой того же клиента с тем же тегом дня. Сравнение показывает прогресс по объёму и по упражнениям, в том числе для тренировок без плана.

## Requirements

### Requirement: Выбор прошлой аналогичной тренировки

- **SHALL** прошлая аналогичная — последняя по времени завершения завершённая тренировка того же тренера, клиента и тега, завершённая строго раньше текущей.
- **MUST NOT** прошлой аналогичной считается тренировка в процессе, с другим тегом, другого клиента или тренера, а также сама текущая.
- **SHALL** правило выбора одинаково для тренировок с планом и без плана.

#### Scenario: Выбрана последняя из нескольких прошлых с тем же тегом

- **GIVEN** у клиента есть завершённые тренировки «ноги» от 01.04 и от 05.04
- **AND** текущая завершённая тренировка «ноги» завершена 07.05
- **WHEN** тренер запрашивает прошлую аналогичную для текущей тренировки
- **THEN** система возвращает тренировку «ноги» от 05.04

#### Scenario: Тренировка с другим тегом не подходит

- **GIVEN** у клиента есть только одна прошлая завершённая тренировка, и её тег «верх»
- **AND** текущая завершённая тренировка имеет тег «ноги»
- **WHEN** тренер запрашивает прошлую аналогичную для текущей тренировки
- **THEN** система сообщает, что прошлой аналогичной тренировки нет

#### Scenario: Тренировка в процессе не подходит

- **GIVEN** у клиента есть тренировка «ноги» в процессе, начатая раньше завершения текущей
- **AND** других тренировок «ноги», кроме текущей, нет
- **WHEN** тренер запрашивает прошлую аналогичную для текущей завершённой тренировки «ноги»
- **THEN** система сообщает, что прошлой аналогичной тренировки нет

#### Scenario: Тренировка другого клиента не подходит

- **GIVEN** у другого клиента того же тренера есть завершённая тренировка «ноги», завершённая раньше текущей
- **AND** у клиента текущей тренировки других тренировок «ноги» нет
- **WHEN** тренер запрашивает прошлую аналогичную для текущей завершённой тренировки «ноги»
- **THEN** система сообщает, что прошлой аналогичной тренировки нет

#### Scenario: Более поздняя тренировка не подходит

- **GIVEN** у клиента есть завершённые тренировки «ноги» от 05.04 и от 10.05
- **AND** тренер смотрит тренировку «ноги» от 07.05
- **WHEN** тренер запрашивает прошлую аналогичную для тренировки от 07.05
- **THEN** система возвращает тренировку «ноги» от 05.04

#### Scenario: Первая тренировка с тегом не имеет прошлой

- **GIVEN** текущая завершённая тренировка — единственная завершённая тренировка клиента с её тегом
- **WHEN** тренер запрашивает прошлую аналогичную для текущей тренировки
- **THEN** система сообщает, что прошлой аналогичной тренировки нет

#### Scenario: Тренировка без плана сравнивается с прошлой того же тега

- **GIVEN** у клиента есть завершённая тренировка «ноги», начатая с плана и завершённая раньше
- **AND** текущая тренировка «ноги» начата без плана и завершена
- **WHEN** тренер запрашивает прошлую аналогичную для текущей тренировки
- **THEN** система возвращает прошлую тренировку «ноги»

### Requirement: Изоляция прошлой аналогичной тренировки по тренеру

- **SHALL** тренерский API возвращает прошлую аналогичную тренировку только для завершённой тренировки клиента текущего тренера.
- **SHALL** система отвечает «не найдено» на запрос прошлой аналогичной для чужой, несуществующей тренировки или тренировки чужого клиента.
- **SHALL** система отвечает пустым результатом на запрос прошлой аналогичной для тренировки в процессе.
- **SHALL** ответ с прошлой аналогичной тренировкой содержит её тег, время завершения и выполненные упражнения с подходами.

#### Scenario: Запрос для тренировки чужого тренера

- **GIVEN** завершённая тренировка принадлежит клиенту другого тренера
- **WHEN** тренер запрашивает прошлую аналогичную для этой тренировки
- **THEN** система отвечает «не найдено»

#### Scenario: Запрос для тренировки в процессе

- **GIVEN** у клиента есть тренировка «ноги» в процессе и завершённая тренировка «ноги» раньше
- **WHEN** тренер запрашивает прошлую аналогичную для тренировки в процессе
- **THEN** система отвечает, что прошлой аналогичной тренировки нет

### Requirement: Переход к сравнению с экрана завершённой тренировки

- **SHALL** экран завершённой тренировки с прошлой аналогичной показывает «С прошлой „<тег>“ (<дата прошлой>)» и действие «Подробнее».
- **MUST NOT** переход показывается, если прошлой аналогичной нет или тренировка в процессе.
- **SHALL** переход показывается для тренировок с планом и без плана в дополнение к их текущему содержимому.

#### Scenario: Есть прошлая с тем же тегом

- **GIVEN** у клиента есть завершённая тренировка «ноги» от 05.04
- **AND** тренер завершил новую тренировку «ноги»
- **WHEN** тренер открывает экран новой завершённой тренировки
- **THEN** экран показывает «С прошлой „ноги“ (05.04.<год>)» и действие «Подробнее»

#### Scenario: Прошлой нет

- **GIVEN** у клиента нет других завершённых тренировок с тегом «ноги»
- **AND** тренер завершил тренировку «ноги»
- **WHEN** тренер открывает экран завершённой тренировки
- **THEN** экран не показывает переход к сравнению с прошлой

#### Scenario: Прошлая только с другим тегом

- **GIVEN** у клиента есть только прошлая завершённая тренировка «верх»
- **AND** тренер завершил тренировку «ноги»
- **WHEN** тренер открывает экран завершённой тренировки
- **THEN** экран не показывает переход к сравнению с прошлой

#### Scenario: Тренировка без плана показывает переход

- **GIVEN** у клиента есть завершённая тренировка «ноги», завершённая раньше
- **AND** тренер завершил тренировку «ноги», начатую без плана
- **WHEN** тренер открывает экран завершённой тренировки
- **THEN** экран показывает пояснение об отсутствии плана и список выполненных подходов
- **AND** экран показывает переход «С прошлой „ноги“» с действием «Подробнее»

### Requirement: Открытие экрана сравнения

- **SHALL** действие «Подробнее» открывает экран сравнения с прошлой аналогичной тренировкой.

#### Scenario: Открытие экрана сравнения

- **GIVEN** экран завершённой тренировки показывает переход к сравнению с прошлой
- **WHEN** тренер нажимает «Подробнее»
- **THEN** открывается экран сравнения с прошлой аналогичной тренировкой

### Requirement: Заголовок экрана сравнения с прошлой

- **SHALL** экран сравнения показывает тег дня, дату завершения текущей тренировки и дату завершения прошлой аналогичной тренировки.
- **SHALL** экран сравнения позволяет вернуться к экрану текущей завершённой тренировки.
- **SHALL** экран сравнения сообщает, что прошлой аналогичной тренировки нет, если её нет или текущая тренировка не завершена.

#### Scenario: Заголовок с датами

- **GIVEN** текущая тренировка «ноги» завершена 07.05, прошлая аналогичная — 05.04
- **WHEN** тренер открывает экран сравнения
- **THEN** экран показывает «Сравнение: ноги»
- **AND** экран показывает дату текущей 07.05 и дату прошлой 05.04

#### Scenario: Прямой переход без прошлой

- **GIVEN** у завершённой тренировки нет прошлой аналогичной
- **WHEN** тренер открывает экран сравнения этой тренировки по прямой ссылке
- **THEN** экран сообщает, что прошлой аналогичной тренировки нет

### Requirement: Сводка по объёму

- **SHALL** экран сравнения показывает объём прошлой тренировки, объём текущей тренировки и разницу объёмов.
- **SHALL** объём тренировки равен сумме произведений повторов на вес в килограммах по всем подходам всех упражнений.
- **SHALL** разница объёмов равна объёму текущей тренировки минус объём прошлой, положительная разница показывается со знаком «+», нулевая — без знака.

#### Scenario: Объём вырос

- **GIVEN** прошлая тренировка содержит подход 8×80 кг
- **AND** текущая тренировка содержит подход 8×82.5 кг
- **WHEN** тренер открывает экран сравнения
- **THEN** сводка показывает объём прошлой «640 кг», текущей «660 кг» и разницу «+20 кг»

### Requirement: Строки по упражнениям

- **SHALL** строка упражнения показывает название, подходы прошлой, подходы текущей и разницу объёма упражнения.
- **SHALL** упражнение из обеих тренировок показывается одной строкой.
- **SHALL** упражнение только из одной тренировки показывается отдельной строкой с «—» на отсутствующей стороне, где объём равен нулю.

#### Scenario: Общее упражнение

- **GIVEN** в прошлой тренировке «Присед» выполнен как 8×80 кг
- **AND** в текущей тренировке «Присед» выполнен как 8×82.5 кг
- **WHEN** тренер открывает экран сравнения
- **THEN** строка «Присед» показывает прошлую «8×80 кг», текущую «8×82.5 кг» и разницу «+20 кг»

#### Scenario: Упражнение только в текущей тренировке

- **GIVEN** «Тяга» есть только в текущей тренировке с подходом 5×100 кг
- **WHEN** тренер открывает экран сравнения
- **THEN** строка «Тяга» показывает прошлую «—», текущую «5×100 кг» и разницу «+500 кг»

#### Scenario: Упражнение только в прошлой тренировке

- **GIVEN** «Жим» есть только в прошлой тренировке с подходом 10×50 кг
- **WHEN** тренер открывает экран сравнения
- **THEN** строка «Жим» показывает прошлую «10×50 кг», текущую «—» и разницу «-500 кг»

### Requirement: Сопоставление повторяющегося упражнения

- **SHALL** при нескольких вхождениях одного упражнения система сначала объединяет в пары вхождения прошлой и текущей тренировок с полностью совпадающими подходами.
- **SHALL** оставшиеся вхождения одного упражнения система объединяет в пары по порядку следования в тренировках.
- **SHALL** вхождения упражнения, оставшиеся без пары, показываются отдельными строками, как упражнение только из одной тренировки.
- **MUST NOT** вхождение одной тренировки входит более чем в одну пару.

#### Scenario: Точное совпадение имеет приоритет над порядком

- **GIVEN** в текущей тренировке «Присед» выполнен дважды: сначала 5×100 кг, затем 8×80 кг
- **AND** в прошлой тренировке «Присед» выполнен дважды: сначала 8×80 кг, затем 5×90 кг
- **WHEN** тренер открывает экран сравнения
- **THEN** вхождение текущей 8×80 кг показано в паре с прошлым 8×80 кг
- **AND** вхождение текущей 5×100 кг показано в паре с прошлым 5×90 кг

#### Scenario: Лишнее вхождение без пары

- **GIVEN** в текущей тренировке «Присед» выполнен дважды: 8×80 кг и 6×85 кг
- **AND** в прошлой тренировке «Присед» выполнен один раз: 6×85 кг
- **WHEN** тренер открывает экран сравнения
- **THEN** вхождение текущей 6×85 кг показано в паре с прошлым 6×85 кг
- **AND** вхождение текущей 8×80 кг показано отдельной строкой с прошлой «—»

### Requirement: Порядок строк сравнения

- **SHALL** строки идут в порядке упражнений текущей тренировки.
- **SHALL** упражнения только из прошлой тренировки идут после них в порядке прошлой тренировки.

#### Scenario: Упражнения только из прошлой — в конце

- **GIVEN** текущая тренировка содержит «Тяга», затем «Присед»
- **AND** прошлая тренировка содержит «Жим», затем «Присед»
- **WHEN** тренер открывает экран сравнения
- **THEN** строки идут в порядке «Тяга», «Присед», «Жим»
