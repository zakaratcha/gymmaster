# workout/split Specification

## Purpose

Функциональность ведёт у клиента пул свободных тегов типа дня (сплит). Тренер пополняет пул и выбирает из него тег при планировании и при старте тренировки без плана, а теги, отличающиеся только регистром, считаются одним тегом.

## Requirements

### Requirement: Чтение пула тегов клиента

- **SHALL** тренерский API возвращает теги пула клиента в порядке их добавления в пул.
- **SHALL** система отвечает «не найдено» на чтение пула чужого или несуществующего клиента.
- **SHALL** система отказывает в доступе к пулу без авторизации.

#### Scenario: Пул нового клиента пуст

- **GIVEN** тренер создал клиента
- **WHEN** тренер запрашивает пул тегов клиента
- **THEN** система возвращает пустой список тегов

#### Scenario: Теги возвращаются в порядке добавления

- **GIVEN** тренер добавил клиенту теги «ноги», затем «верх», затем «день А»
- **WHEN** тренер запрашивает пул тегов клиента
- **THEN** система возвращает теги «ноги», «верх», «день А» в этом порядке

#### Scenario: Пул клиента другого тренера

- **GIVEN** клиент принадлежит другому тренеру
- **WHEN** тренер запрашивает пул тегов этого клиента
- **THEN** система отвечает «не найдено»

#### Scenario: Запрос без авторизации

- **GIVEN** пользователь не авторизован
- **WHEN** пользователь запрашивает пул тегов клиента
- **THEN** система отказывает в доступе

### Requirement: Пополнение пула тегов клиента

- **SHALL** тренерский API добавляет тег в пул клиента после обрезки пробелов по краям и возвращает обновлённый пул.
- **SHALL** теги, совпадающие после обрезки пробелов без учёта регистра, — один тег; в пуле остаётся написание, добавленное первым.
- **MUST NOT** система добавляет пустой тег или тег из одних пробелов.
- **SHALL** система отвечает «не найдено» на пополнение пула чужого или несуществующего клиента.

#### Scenario: Тег добавляется без пробелов по краям

- **GIVEN** пул клиента пуст
- **WHEN** тренер добавляет в пул тег « ноги »
- **THEN** пул клиента содержит один тег «ноги»

#### Scenario: Тег в другом регистре не дублируется

- **GIVEN** пул клиента содержит тег «ноги»
- **WHEN** тренер добавляет в пул тег «Ноги»
- **THEN** пул клиента содержит один тег «ноги»

#### Scenario: Пустой тег отклоняется

- **GIVEN** тренер авторизован
- **WHEN** тренер добавляет в пул клиента тег из одних пробелов
- **THEN** система отвечает ошибкой валидации
- **AND** пул клиента не меняется

#### Scenario: Пополнение пула клиента другого тренера

- **GIVEN** клиент принадлежит другому тренеру
- **WHEN** тренер добавляет тег в пул этого клиента
- **THEN** система отвечает «не найдено»

### Requirement: Тег плана и тренировки сводится к пулу

- **SHALL** создание и изменение плана и старт тренировки сохраняют тег в написании из пула клиента, если пул содержит тот же тег в другом регистре.
- **SHALL** тег, которого нет в пуле клиента, после создания или изменения плана либо старта тренировки добавляется в пул.
- **MUST NOT** отклонённый запрос на создание или изменение плана либо старт тренировки меняет пул.

#### Scenario: Новый тег плана попадает в пул

- **GIVEN** пул клиента не содержит тег «спина»
- **WHEN** тренер создаёт план клиенту с тегом «спина»
- **THEN** пул клиента содержит тег «спина»

#### Scenario: Тег плана в другом регистре сохраняется в написании пула

- **GIVEN** пул клиента содержит тег «ноги»
- **WHEN** тренер создаёт план клиенту с тегом «Ноги»
- **THEN** созданный план имеет тег «ноги»
- **AND** пул клиента содержит один тег «ноги»

#### Scenario: Изменённый тег плана попадает в пул

- **GIVEN** у клиента есть план с тегом «ноги»
- **WHEN** тренер меняет тег плана на «плечи»
- **THEN** пул клиента содержит тег «плечи»

#### Scenario: Изменённый тег плана в другом регистре сохраняется в написании пула

- **GIVEN** пул клиента содержит тег «верх»
- **AND** у клиента есть план с тегом «ноги»
- **WHEN** тренер меняет тег плана на «ВЕРХ»
- **THEN** план имеет тег «верх»
- **AND** пул клиента содержит один тег «верх»

#### Scenario: Тренировка с плана сохраняет тег в написании пула

- **GIVEN** у клиента есть план с тегом «ноги»
- **AND** у клиента нет тренировки в процессе
- **WHEN** тренер начинает тренировку с этого плана
- **THEN** начатая тренировка имеет тег «ноги»
- **AND** пул клиента содержит один тег «ноги»

#### Scenario: Отклонённое создание плана не меняет пул

- **GIVEN** пул клиента не содержит тег «спина»
- **WHEN** тренер создаёт план клиенту с тегом «спина» и несуществующим упражнением
- **THEN** система отвечает ошибкой валидации
- **AND** пул клиента не содержит тег «спина»

#### Scenario: Отклонённое изменение плана не меняет пул

- **GIVEN** у клиента есть план с тегом «ноги»
- **AND** пул клиента не содержит тег «плечи»
- **WHEN** тренер меняет тег плана на «плечи» вместе с несуществующим упражнением
- **THEN** система отвечает ошибкой валидации
- **AND** пул клиента не содержит тег «плечи»

#### Scenario: Тег тренировки без плана сводится к пулу

- **GIVEN** пул клиента содержит тег «ноги»
- **WHEN** тренер начинает тренировку клиента без плана с тегом «НОГИ»
- **THEN** начатая тренировка имеет тег «ноги»

#### Scenario: Новый тег тренировки без плана попадает в пул

- **GIVEN** пул клиента не содержит тег «кардио»
- **WHEN** тренер начинает тренировку клиента без плана с тегом «кардио»
- **THEN** пул клиента содержит тег «кардио»

#### Scenario: Отклонённый старт не меняет пул

- **GIVEN** у клиента есть тренировка в процессе
- **AND** пул клиента не содержит тег «кардио»
- **WHEN** тренер начинает ещё одну тренировку клиента без плана с тегом «кардио»
- **THEN** система отклоняет старт
- **AND** пул клиента не содержит тег «кардио»

### Requirement: Блок «Сплит» на карточке клиента

- **SHALL** блок «Сплит» показывает теги пула клиента в порядке добавления.
- **SHALL** при пустом пуле блок показывает «Тегов пока нет».
- **MUST NOT** блок показывает метку «Скоро» и кнопку настроек сплита.
- **SHALL** при ошибке загрузки пула блок показывает «Не удалось загрузить теги» и действие «Повторить».
- **MUST NOT** повтор загрузки пула прерывает незавершённую загрузку других секций карточки, а повтор другой секции — незавершённую загрузку пула.

#### Scenario: Блок показывает теги пула

- **GIVEN** пул клиента содержит теги «ноги» и «верх»
- **WHEN** тренер открывает карточку клиента
- **THEN** блок «Сплит» показывает теги «ноги» и «верх»
- **AND** блок не показывает метку «Скоро» и кнопку настроек сплита

#### Scenario: Пустой пул

- **GIVEN** пул клиента пуст
- **WHEN** тренер открывает карточку клиента
- **THEN** блок «Сплит» показывает «Тегов пока нет»

#### Scenario: Повтор после ошибки загрузки

- **GIVEN** пул клиента содержит тег «ноги»
- **AND** первая загрузка пула завершилась ошибкой
- **WHEN** тренер нажимает «Повторить» в блоке «Сплит»
- **THEN** блок «Сплит» показывает тег «ноги»

#### Scenario: Повтор загрузки пула не прерывает загрузку планов

- **GIVEN** пул клиента содержит тег «ноги», у клиента есть план с тегом «верх»
- **AND** загрузка планов на карточке ещё не завершилась
- **AND** первая загрузка пула завершилась ошибкой
- **WHEN** тренер нажимает «Повторить» в блоке «Сплит»
- **AND** загрузка планов завершается
- **THEN** блок «Сплит» показывает тег «ноги»
- **AND** карточка показывает ближайший план «верх»
- **AND** действие «Старт с плана» доступно

#### Scenario: Повтор загрузки планов не прерывает загрузку пула

- **GIVEN** пул клиента содержит тег «ноги», у клиента есть план с тегом «верх»
- **AND** загрузка пула на карточке ещё не завершилась
- **AND** первая загрузка планов завершилась ошибкой
- **WHEN** тренер нажимает «Повторить» в секции планов
- **AND** загрузка пула завершается
- **THEN** блок «Сплит» показывает тег «ноги»
- **AND** карточка показывает ближайший план «верх»

### Requirement: Добавление тега с карточки клиента

- **SHALL** действие «+ тег» в блоке «Сплит» открывает диалог ввода нового тега.
- **SHALL** подтверждение диалога добавляет тег в пул, закрывает диалог и показывает пул в блоке «Сплит».
- **SHALL** диалог с пустым тегом показывает «Укажите тег» и не отправляет запрос.
- **SHALL** при ошибке сохранения диалог остаётся открытым с введённым тегом и показывает «Не удалось добавить тег».

#### Scenario: Добавленный тег появляется в блоке

- **GIVEN** пул клиента содержит тег «ноги»
- **WHEN** тренер добавляет через «+ тег» тег «верх»
- **THEN** блок «Сплит» показывает теги «ноги» и «верх»

#### Scenario: Добавленный тег сохраняется после перезагрузки

- **GIVEN** пул клиента пуст
- **WHEN** тренер добавляет через «+ тег» тег «верх»
- **AND** тренер перезагружает карточку клиента
- **THEN** блок «Сплит» показывает тег «верх»

#### Scenario: Тег в другом регистре не дублируется в блоке

- **GIVEN** пул клиента содержит тег «ноги»
- **WHEN** тренер добавляет через «+ тег» тег «Ноги»
- **THEN** блок «Сплит» показывает только тег «ноги»

#### Scenario: Пустой тег не отправляется

- **GIVEN** тренер открыл диалог «+ тег»
- **WHEN** тренер подтверждает диалог с пустым тегом
- **THEN** диалог остаётся открытым и показывает «Укажите тег»

#### Scenario: Ошибка сохранения тега

- **GIVEN** тренер открыл диалог «+ тег» и ввёл тег «верх»
- **AND** сохранение тега завершается ошибкой
- **WHEN** тренер подтверждает диалог
- **THEN** диалог остаётся открытым с тегом «верх» и показывает «Не удалось добавить тег»

### Requirement: Подсказки тега при выборе

- **SHALL** поле тега дня в редакторе плана и в диалоге «Пустая сессия» показывает подсказки — теги пула клиента, содержащие введённый текст без учёта регистра, в порядке пула.
- **SHALL** при пустом поле подсказки — все теги пула.
- **MUST NOT** подсказки содержат тег, совпадающий с введённым без учёта регистра.
- **SHALL** выбор подсказки подставляет тег в поле, а поле принимает и новый тег, которого нет в пуле.

#### Scenario: Точное совпадение не подсказывается

- **GIVEN** пул клиента содержит теги «ноги» и «верх»
- **AND** тренер открыл редактор нового плана клиента
- **WHEN** тренер вводит в поле тега «НОГИ»
- **THEN** подсказки не показывают ни одного тега

#### Scenario: Подсказки фильтруются по введённому тексту

- **GIVEN** пул клиента содержит теги «ноги», «верх» и «Ноги-2»
- **AND** тренер открыл редактор нового плана клиента
- **WHEN** тренер вводит в поле тега «НО»
- **THEN** подсказки показывают «ноги» и «Ноги-2»
- **AND** подсказки не показывают «верх»

#### Scenario: Выбор подсказки в редакторе плана

- **GIVEN** пул клиента содержит тег «ноги»
- **AND** тренер открыл редактор нового плана клиента
- **WHEN** тренер выбирает подсказку «ноги»
- **AND** сохраняет план
- **THEN** список планов клиента показывает план с тегом «ноги»

#### Scenario: Новый тег из редактора плана появляется в блоке «Сплит»

- **GIVEN** пул клиента не содержит тег «спина»
- **WHEN** тренер создаёт в редакторе план с тегом «спина»
- **AND** тренер открывает карточку клиента
- **THEN** блок «Сплит» показывает тег «спина»

### Requirement: Редактор плана при ошибке загрузки пула

- **SHALL** при ошибке загрузки пула редактор плана работает без подсказок и сохраняет план с тегом, введённым вручную.

#### Scenario: Ошибка загрузки пула не блокирует редактор плана

- **GIVEN** загрузка пула клиента завершается ошибкой
- **AND** тренер открыл редактор нового плана клиента
- **WHEN** тренер вводит тег «ноги» вручную и сохраняет план
- **THEN** список планов клиента показывает план с тегом «ноги»

### Requirement: Старт тренировки без плана

- **SHALL** карточка клиента показывает действие «Пустая сессия», которое открывает диалог с полем тега дня и подсказками из пула.
- **SHALL** подтверждение диалога начинает тренировку без плана с указанным тегом и открывает её экран.
- **SHALL** диалог с пустым тегом показывает «Укажите тег дня» и не начинает тренировку.

#### Scenario: Старт с тегом из подсказки

- **GIVEN** пул клиента содержит тег «ноги»
- **AND** у клиента нет тренировки в процессе
- **WHEN** тренер открывает «Пустая сессия», выбирает подсказку «ноги» и начинает тренировку
- **THEN** открывается экран тренировки с тегом «ноги»

#### Scenario: Новый тег пустой сессии появляется в блоке «Сплит»

- **GIVEN** пул клиента не содержит тег «кардио»
- **AND** у клиента нет тренировки в процессе
- **WHEN** тренер начинает «Пустая сессия» с тегом «кардио»
- **AND** тренер открывает карточку клиента
- **THEN** блок «Сплит» показывает тег «кардио»

#### Scenario: Пустой тег не начинает тренировку

- **GIVEN** тренер открыл диалог «Пустая сессия»
- **WHEN** тренер начинает тренировку с пустым тегом
- **THEN** диалог остаётся открытым и показывает «Укажите тег дня»

### Requirement: Доступность старта тренировки без плана

- **MUST NOT** действие «Пустая сессия» доступно, пока у клиента есть тренировка в процессе.
- **SHALL** доступность действия «Пустая сессия» не зависит от наличия планов и от ошибки их загрузки.

#### Scenario: Действие недоступно при тренировке в процессе

- **GIVEN** у клиента есть тренировка в процессе
- **WHEN** тренер открывает карточку клиента
- **THEN** действие «Пустая сессия» недоступно

#### Scenario: Действие доступно без планов

- **GIVEN** у клиента нет планов и нет тренировки в процессе
- **WHEN** тренер открывает карточку клиента
- **THEN** действие «Пустая сессия» доступно
- **AND** действие «Старт с плана» недоступно

#### Scenario: Действие доступно при ошибке загрузки планов

- **GIVEN** у клиента нет тренировки в процессе
- **AND** загрузка планов завершается ошибкой
- **WHEN** тренер открывает карточку клиента
- **THEN** действие «Пустая сессия» доступно

### Requirement: Ошибка старта тренировки без плана

- **SHALL** при отказе сервера диалог остаётся открытым с введённым тегом и показывает «Клиент не найден», если клиента нет, или «У клиента уже есть тренировка в процессе», если она уже начата.

#### Scenario: Клиент не найден при старте

- **GIVEN** тренер открыл диалог «Пустая сессия» и ввёл тег «ноги»
- **AND** сервер отвечает на старт «не найдено»
- **WHEN** тренер начинает тренировку
- **THEN** диалог остаётся открытым с тегом «ноги» и показывает «Клиент не найден»

#### Scenario: Тренировка уже начата при старте

- **GIVEN** тренер открыл диалог «Пустая сессия» и ввёл тег «ноги»
- **AND** сервер отвечает на старт, что у клиента уже есть тренировка в процессе
- **WHEN** тренер начинает тренировку
- **THEN** диалог остаётся открытым с тегом «ноги» и показывает «У клиента уже есть тренировка в процессе»
