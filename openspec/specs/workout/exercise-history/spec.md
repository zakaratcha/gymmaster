# workout/exercise-history Specification

## Purpose

Функциональность показывает тренеру историю одного упражнения у одного клиента: хронологию завершённых тренировок с фактическими подходами. Так видно, как росли веса и повторы. История открывается с карточки клиента, с экрана завершённой тренировки и с вкладки текущей тренировки.

## Requirements

### Requirement: Состав истории упражнения

- **SHALL** история упражнения у клиента включает завершённые тренировки текущего тренера и этого клиента, в факте которых у упражнения есть хотя бы один подход.
- **MUST NOT** в историю попадают тренировки в процессе, тренировки других клиентов, тренировки других тренеров и тренировки, где у упражнения нет ни одного подхода.
- **SHALL** упражнение в архиве сохраняет историю по прошлым тренировкам.

#### Scenario: Завершённые тренировки с упражнением попадают в историю

- **GIVEN** у клиента есть завершённые тренировки от 05.04 и от 07.05, в обеих есть подходы «Присед»
- **WHEN** тренер открывает историю «Присед» у клиента
- **THEN** история содержит тренировки от 07.05 и от 05.04

#### Scenario: Тренировка без упражнения не попадает

- **GIVEN** у клиента есть завершённая тренировка, где выполнялся только «Жим»
- **WHEN** тренер открывает историю «Присед» у клиента
- **THEN** история не содержит эту тренировку

#### Scenario: Упражнение без подходов не попадает

- **GIVEN** у клиента есть завершённая тренировка, где «Присед» добавлен без единого подхода
- **WHEN** тренер открывает историю «Присед» у клиента
- **THEN** история не содержит эту тренировку

#### Scenario: Тренировка в процессе не попадает

- **GIVEN** у клиента есть тренировка в процессе с подходами «Присед»
- **AND** завершённых тренировок с «Присед» у клиента нет
- **WHEN** тренер открывает историю «Присед» у клиента
- **THEN** история пуста

#### Scenario: Тренировка другого клиента не попадает

- **GIVEN** у другого клиента того же тренера есть завершённая тренировка с подходами «Присед»
- **AND** у выбранного клиента тренировок с «Присед» нет
- **WHEN** тренер открывает историю «Присед» у выбранного клиента
- **THEN** история пуста

#### Scenario: Архивное упражнение сохраняет историю

- **GIVEN** у клиента есть завершённая тренировка с подходами «Присед»
- **AND** тренер перенёс «Присед» в архив
- **WHEN** тренер открывает историю «Присед» у клиента
- **THEN** история содержит эту тренировку

### Requirement: Порядок и содержимое строк истории

- **SHALL** строки истории упорядочены по времени завершения тренировки, от новых к старым.
- **SHALL** строка истории показывает дату завершения тренировки и фактические подходы упражнения в этой тренировке.
- **SHALL** каждой тренировке соответствует одна строка. Если упражнение встречается в тренировке несколько раз, строка содержит подходы всех вхождений в порядке выполнения.

#### Scenario: Новые тренировки сверху

- **GIVEN** у клиента есть завершённые тренировки с «Присед» от 05.04, 07.05 и 01.03
- **WHEN** тренер открывает историю «Присед» у клиента
- **THEN** строки идут в порядке 07.05, 05.04, 01.03

#### Scenario: Повтор упражнения в одной тренировке

- **GIVEN** в завершённой тренировке «Присед» выполнен дважды: сначала 8×80 кг, затем 5×100 кг
- **WHEN** тренер открывает историю «Присед» у клиента
- **THEN** история содержит одну строку для этой тренировки
- **AND** строка показывает подходы «1×8@80 · 1×5@100»

### Requirement: Формат подходов в истории

- **SHALL** подряд идущие подходы с одинаковыми повторами и весом показываются группой «<число подходов>×<повторы>@<вес в кг>».
- **SHALL** группы подходов разделяются « · » и идут в порядке выполнения.
- **SHALL** вес показывается в килограммах без единицы измерения, дробный вес — с десятичной точкой.

#### Scenario: Одинаковые подходы

- **GIVEN** в тренировке «Присед» выполнен четырьмя подходами 8×82.5 кг
- **WHEN** тренер открывает историю «Присед» у клиента
- **THEN** строка этой тренировки показывает подходы «4×8@82.5»

#### Scenario: Разные подходы

- **GIVEN** в тренировке «Присед» выполнены подходы 8×80 кг, 8×80 кг и 6×85 кг
- **WHEN** тренер открывает историю «Присед» у клиента
- **THEN** строка этой тренировки показывает подходы «2×8@80 · 1×6@85»

#### Scenario: Одинаковые подходы не подряд

- **GIVEN** в тренировке «Присед» выполнены подходы 8×80 кг, 6×85 кг и 8×80 кг
- **WHEN** тренер открывает историю «Присед» у клиента
- **THEN** строка этой тренировки показывает подходы «1×8@80 · 1×6@85 · 1×8@80»

### Requirement: Изоляция истории упражнения по тренеру

- **SHALL** тренерский API возвращает историю упражнения только для клиента и упражнения текущего тренера.
- **SHALL** система отвечает «не найдено» на запрос истории для чужого или несуществующего клиента или упражнения.
- **SHALL** для упражнения и клиента текущего тренера без подходящих тренировок система отвечает пустой историей.
- **SHALL** ответ с историей содержит имя клиента, название упражнения и строки истории.

#### Scenario: Чужой клиент

- **GIVEN** клиент принадлежит другому тренеру
- **WHEN** тренер запрашивает историю своего упражнения у этого клиента
- **THEN** система отвечает «не найдено»

#### Scenario: Чужое упражнение

- **GIVEN** упражнение принадлежит другому тренеру
- **WHEN** тренер запрашивает историю этого упражнения у своего клиента
- **THEN** система отвечает «не найдено»

#### Scenario: Несуществующее упражнение

- **GIVEN** упражнения с указанным идентификатором нет
- **WHEN** тренер запрашивает его историю у своего клиента
- **THEN** система отвечает «не найдено»

#### Scenario: Своё упражнение без тренировок

- **GIVEN** у клиента нет завершённых тренировок с «Присед»
- **WHEN** тренер запрашивает историю «Присед» у клиента
- **THEN** система отвечает пустой историей с именем клиента и названием упражнения

### Requirement: Экран истории упражнения

- **SHALL** экран истории показывает заголовок «История: <упражнение> · <клиент>».
- **SHALL** экран истории показывает таблицу со столбцами «Дата» и «Подходы».
- **SHALL** экран истории позволяет закрыть его и вернуться туда, откуда он был открыт.

#### Scenario: Заголовок и таблица

- **GIVEN** у клиента «Анна» есть завершённая тренировка от 07.05 с четырьмя подходами «Присед» 8×82.5 кг
- **WHEN** тренер открывает историю «Присед» у клиента
- **THEN** экран показывает заголовок «История: Присед · Анна»
- **AND** таблица содержит строку с датой 07.05.<год> и подходами «4×8@82.5»

### Requirement: Состояния экрана истории

- **SHALL** во время загрузки экран истории показывает индикатор загрузки в области контента.
- **SHALL** при пустой истории экран показывает «Нет завершённых тренировок с этим упражнением».
- **SHALL** при ошибке загрузки экран показывает сообщение об ошибке и действие «Повторить», которое загружает историю заново.

#### Scenario: Пустая история

- **GIVEN** у клиента нет завершённых тренировок с «Присед»
- **WHEN** тренер открывает историю «Присед» у клиента
- **THEN** экран показывает «Нет завершённых тренировок с этим упражнением»

#### Scenario: Повтор после ошибки

- **GIVEN** при открытии экрана истории загрузка завершилась ошибкой
- **WHEN** тренер нажимает «Повторить»
- **THEN** экран загружает историю заново и показывает её

### Requirement: Вход с карточки клиента

- **SHALL** в разделе «История» карточки клиента есть действие «История упражнения…».
- **SHALL** действие предлагает выбрать упражнение из рабочего списка справочника и открывает экран истории выбранного упражнения у этого клиента.
- **MUST NOT** выбор предлагает упражнения из архива.

#### Scenario: Выбор упражнения на карточке

- **GIVEN** тренер на карточке клиента «Анна»
- **WHEN** тренер выбирает «История упражнения…» и упражнение «Присед»
- **THEN** открывается экран «История: Присед · Анна»

#### Scenario: Архивное упражнение не предлагается

- **GIVEN** упражнение «Выпады» в архиве
- **WHEN** тренер выбирает «История упражнения…» на карточке клиента
- **THEN** список выбора не содержит «Выпады»

### Requirement: Вход с экрана завершённой тренировки

- **SHALL** у каждой строки упражнения на экране завершённой тренировки есть действие открытия истории этого упражнения у клиента тренировки.
- **SHALL** действие есть и в строках сравнения с планом, и в списке выполненных подходов тренировки без плана.
- **MUST NOT** действие меняет содержимое и статусы строк сравнения с планом.

#### Scenario: Тренировка с планом

- **GIVEN** тренер на экране завершённой тренировки клиента «Анна», начатой с плана, где есть «Присед»
- **WHEN** тренер открывает историю из строки «Присед»
- **THEN** открывается экран «История: Присед · Анна»

#### Scenario: Тренировка без плана

- **GIVEN** тренер на экране завершённой тренировки клиента «Анна» без плана, где выполнен «Присед»
- **WHEN** тренер открывает историю из строки «Присед»
- **THEN** открывается экран «История: Присед · Анна»

#### Scenario: Упражнение из плана, которое не выполнено

- **GIVEN** в плане завершённой тренировки был «Жим», но в факте его нет
- **WHEN** тренер открывает историю из строки «Жим»
- **THEN** открывается экран истории «Жим» у клиента тренировки

### Requirement: Вход с вкладки текущей тренировки

- **SHALL** в заголовке каждой карточки упражнения на вкладке тренировки в процессе есть иконочная кнопка открытия истории этого упражнения у клиента тренировки.
- **SHALL** история открывается поверх вкладки тренировки, закрытие возвращает на ту же вкладку.
- **MUST NOT** открытие и закрытие истории сбрасывают введённые на вкладке данные тренировки.
- **MUST NOT** история включает текущую тренировку в процессе.

#### Scenario: Открытие истории с вкладки

- **GIVEN** у клиента «Анна» идёт тренировка с «Присед»
- **AND** есть завершённая тренировка от 05.04 с подходами «Присед»
- **WHEN** тренер нажимает кнопку истории в заголовке карточки «Присед»
- **THEN** поверх вкладки открывается «История: Присед · Анна» со строкой от 05.04

#### Scenario: Закрытие истории сохраняет тренировку

- **GIVEN** тренер ввёл на вкладке тренировки подход «Присед»
- **AND** открыл историю «Присед» с этой вкладки
- **WHEN** тренер закрывает историю
- **THEN** вкладка тренировки показывает введённый подход «Присед»
